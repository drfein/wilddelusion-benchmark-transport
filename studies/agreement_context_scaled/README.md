# Scaled agreement-context intervention

This outcome-independent follow-up separates the causal effects of the
immediately preceding assistant stance and earlier accumulated assistant
stance on GPT-4.1-mini endorsement. It uses one target from every eligible
non-pilot conversation and three matched context arms.

See `PREREGISTRATION.md` for the frozen design. Raw conversations, rewrites,
generations, and judgment rationales remain under gitignored `artifacts/`.

## Result

The scaled outcome-independent study is complete. Agreement preservation
produced 19.0% endorsement versus 19.9% after local neutralization, an
immediate-stance effect of -0.93 percentage points (95% CI -3.24 to +1.39).
The outcome-selected pilot's positive effect did not replicate. See
`RESULTS.md` for the cumulative intervention limitations and full analysis.
